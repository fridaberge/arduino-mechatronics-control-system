# Media — Assignment 2

Pictures, screenshots and illustrations supporting the voltage-divider assignment in **IN1080: Mechatronics**.

## Purpose

This folder collects the visual material associated with the assignment, such as:

- Python-generated plots.
- Arduino serial-output screenshots.
- Circuit illustrations.
- Pictures documenting the practical work.

The written explanations, calculations and interpretation of the results are in [oblig2_fridatbe.pdf](../oblig2_fridatbe.pdf).

## Interpreting the Media

The files should be read alongside the report and task description:

- Plots illustrate the theoretical calculations.
- Serial-output screenshots show recorded analog readings.
- Circuit illustrations help explain the intended wiring.
- Pictures document the setup but do not independently verify its electrical connections.

Some material comes from the original submission and may not fully match the assignment requirements. The main README documents known discrepancies.

The Python scripts are stored in [code/](../code/).
